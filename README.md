# 🧠 Linear Models for Classification


## 📖 О проекте

Проект выполнен в рамках курса **"Машинное обучение"** (ВМК МГУ) и посвящен исследованию линейных моделей для задач классификации. 

### 🎯 Цели исследования

- Изучить проблему **переобучения** в линейных моделях и методы борьбы с ним
- Научиться работать с **различными типами признаков** (категориальные, числовые)
- Понять различия между **регуляризаторами** (L1, L2)
- Исследовать сходимость различных методов оптимизации

### 🧪 Основные эксперименты

| Эксперимент | Описание |
|-------------|----------|
| **Сравнение оптимизаторов** | Анализ сходимости LBFGS vs Newton-CG на синтетических данных |
| **Кодирование признаков** | Реализация One-Hot Encoding и счетчиковых признаков |
| **Регуляризация** | Исследование влияния регуляризации на качество модели |
| **Работа с реальными данными** | Прогнозирование осадков с использованием линейных моделей |

## Ключевые результаты
